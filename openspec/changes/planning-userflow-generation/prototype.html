비화면 spec (1)

🔌 planning-userflow-view (비화면 spec)

flowforge가 Mermaid 유저플로우를 SpecGraph로 파싱해 제공한다
  • 유저플로우 그래프 조회 성공: HTTP 200과 함께 노드·엣지를 담은 SpecGraph와 저장된 layout(없으면 빈 객체)을 반환한다
  • Mermaid 노드 모양이 노드 kind로 매핑된다: 각 노드가 대응 kind(start/screen/action 등)로 파싱돼 반환된다
  • Mermaid 엣지가 그래프 엣지로 변환된다: source/target이 이어진 엣지로 변환되고, `|라벨|`은 엣지 label로 보존된다
  • 유저플로우 파일 없으면 안전한 4xx: 500이 아니라 404로 안전하게 응답한다
드래그 좌표를 overlay JSON에 저장한다
  • 좌표 저장 후 재조회 시 반영: `<group>-vN.overlay.json`에 좌표가 기록되고, 재조회 layout에 그 좌표가 포함된다
  • overlay 저장은 명세 .md를 변경하지 않는다: `<group>-vN.md`(Mermaid 명세)는 수정·삭제되지 않고, overlay JSON만 쓰인다
쓰기 라우트의 경로안전·입력검증 불변
  • 경로 조작 차단 (읽기·쓰기 모두): 4xx로 차단하고 docs 디렉토리 밖 파일을 읽거나 쓰지 않는다
  • 잘못된 layout body 거부: `isLayoutOverlay` 검증 실패로 4xx를 반환하고 파일을 쓰지 않는다
