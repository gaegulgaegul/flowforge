비화면 spec (1)

🔌 planning-features-generation (비화면 spec)

openspec-plan이 features.md를 의존성 순서로 생성한다
  • PRD 다음 단계로 features.md 생성: `docs/planning/features.md`가 3단 트리 + 노드 속성 + capability 키 스키마로 생성된다
features.md는 확정 스키마를 따른다
  • 요구사항에 capability 키가 부여된다: 각 요구사항에 `<!-- capability: <영문키> -->` 주석이 있어 매핑의 출발점이 된다
  • 노드에 중요도·상태 속성이 있다: 중요도(낮음/중간/높음)와 상태(시작전/진행중/완료/중단) 속성이 표기돼 있다
