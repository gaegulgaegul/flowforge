PRD — 기획 단계 산출물
제안이 없습니다. PRD를 읽기 전용으로 표시합니다(승인 UI 숨김).
화면 흐름
  1. skeleton 단계 진입 → 프로젝트의 제안 큐를 fetch.
  2. 제안 ≥1건 → 상태 A(섹션별 현재 vs 제안 카드 + 개별 [승인]/[반려] + 하단 [모두 승인]/[모두 반려]).
  3. 개별 승인 → 그 섹션만 prd.md에 교체 반영, 큐에서 제거. 반려 → 반영 없이 큐에서 제거(원본 불변).
  4. 제출 후 PRD·큐 재조회(dashReqToken race 가드). 큐가 비면 → 상태 B(순수 읽기 뷰).
  5. 미실재 섹션/id는 skipped로 표면화(silent drop 금지). 파싱 실패 시 422로 원본 보호.
